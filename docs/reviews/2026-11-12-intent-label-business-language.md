# 意图评测 V1 业务标签修正复核

## 问题与修复边界

前次重构把面向用户的意图标签转换为数据库实体、字段与 SQL 表达式，违背了标签用于确认用户需求的用途。本次以原始中文业务标注为依据恢复标签，并在 `evals/AGENTS.md` §4.3.1 固定硬性规则：业务对象、条件及取值使用用户语言；指标用业务统计口径描述；禁止物理名称、内部编码、SQL 和表关联执行细节。工具 JSON 键名与控制字段按接口结构保留。

本次修复现有 V1，不扩充题库、不调整去重决策。保留题目、ID、input、分类、难度与来源标识；Langfuse 沿用同一批 DatasetItem ID，以服务端版本历史追溯更正。修正标识为 `metadata.annotation_revision=business-language-r01`。
