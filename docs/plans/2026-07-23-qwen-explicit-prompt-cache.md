# Qwen 显式提示词缓存适配实施计划

## 目标

在不修改 DeerFlow 主智能体执行流程、公共图结构和中间件链的前提下，先通过真实 DashScope `qwen3.6-plus` 请求验证显式上下文缓存，再在现有模型 Provider 扩展层增加可配置的 Qwen 显式缓存能力，并完整保留缓存创建、命中用量统计。

## 约束

- 复用 `create_chat_model()` 与现有自定义 Provider 扩展点，不新增 DataAgent 专属图、路由或中间件。
- 默认行为保持兼容：未显式配置时，不改变已有 OpenAI 兼容模型请求。
- 后端新增代码必须使用中文注释，并在需求新增位置标记 `# ADD: 代码描述`。
- 真实模型测试不得打印 API Key、完整系统提示词或业务数据。
- 测试使用长度达到厂商最低缓存要求的人工固定前缀，不使用真实用户对话。
