# DataAgent 查询意图卡底部提交按钮无响应问题

## 1. 现象

- 查询意图卡中，逐项按钮可以显示状态变化。
- 底部“仅生成 SQL”和“确认并生成 SQL”点击后没有发起提交，只有“取消查询”可用。

## 2. 根因

- 前端在提交最终审批时，强制要求所有待确认项都先手动点过“按当前理解继续/修改这一项”。
- 这和真实交互不符：底部按钮本应代表“按当前理解直接提交”，未单独处理的项应默认接受当前理解。
- 因此，用户不逐项点完时，提交逻辑在前端就直接返回了，后端根本收不到请求。

## 3. 修复

- 增加查询意图提交组装函数：未手动操作的待确认项默认按 `accept` 处理。
- 仅当用户明确选择“修改这一项”但未填写内容时，才阻止提交。
- 增加单测覆盖“未逐项选择也能直接提交最终审批”的场景。
