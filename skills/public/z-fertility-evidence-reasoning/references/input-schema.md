# 输入结构说明

## 目标

把用户提供的病历转换成“生育单元病例档案”。不要默认只分析女方，也不要默认所有病例都是异性夫妻。先识别生育角色，再判断哪些信息是必需、重要或可选。

## 默认输入对象

### 生育单元基本信息

- 当前问题：不孕、不明原因不孕、畸形精子症、少弱精、无精症、排卵障碍、PCOS、输卵管因素、子宫因素、内异症、卵巢储备下降、反复种植失败、反复妊娠丢失、ART 方案评估等。
- 试孕时长、同居情况、性生活频率、排卵期同房情况。
- 既往共同妊娠史、流产史、异位妊娠史、活产史。
- 既往促排、IUI、IVF、ICSI、PGT、取卵、移植和冻胚记录。
- 当前目标：自然妊娠、IUI、IVF、ICSI、PGT、供精、供卵、胚胎移植、冻卵/冻胚、生育力保存等。
- 病历来源日期、检查日期、治疗日期和报告单位。

### 卵子来源方资料

- 年龄、身高、体重、BMI。
- 月经周期、经量、痛经、闭经/稀发排卵、异常出血。
- AMH、AFC、基础 FSH/LH/E2、黄体期孕酮或其他排卵证据。
- PCOS 相关资料：高雄激素表现或实验室证据、卵巢多囊样改变或 AMH、是否排除其他病因。
- 甲状腺、泌乳素、糖代谢、慢性病、用药、放化疗、卵巢手术史。
- 输卵管评估：HSG、HyCoSy、腹腔镜、既往盆腔炎/结核/异位妊娠/手术史。
- 宫腔和子宫评估：超声、宫腔镜、肌瘤、息肉、粘连、纵隔、腺肌症、内膜异常。
- 子宫内膜异位症证据：症状、影像、手术分期、卵巢巧囊、盆腔粘连。

### 精子来源方资料

- 年龄、身高、体重、吸烟饮酒、热暴露、毒物或职业暴露。
- 生殖史：既往生育、隐睾、腮腺炎睾丸炎、外伤、手术、放化疗、感染、发热、用药、睾酮或合成代谢类固醇使用。
- 性功能和射精功能：勃起、射精、性交困难、逆行射精可能。
- 男科查体：睾丸体积、输精管是否可触及、精索静脉曲张、附睾异常。
- 精液分析：检查日期、禁欲天数、体积、pH、浓度、总精子数、前向运动率、总活动率、形态率、活率、白细胞/圆细胞、是否离心后仍无精子。
- 是否至少重复一次精液分析，特别是在异常时。
- 激素：FSH、LH、总睾酮、催乳素、雌二醇，按适应证。
- 遗传检查：核型、Y 染色体微缺失、CFTR，按适应证。

### 子宫/妊娠承载方资料

当妊娠承载方与卵子来源方不同，需单独记录：

- 年龄、既往妊娠和分娩史。
- 子宫、宫腔、内膜、宫颈相关检查。
- 慢性病、用药、感染筛查和妊娠禁忌证。
- 当地法律、伦理和知情同意要求。

### 胚胎和 ART 周期资料

- 促排方案、起始剂量、用药天数、触发方式。
- 获卵数、成熟卵数、受精方式、正常受精数、卵裂、囊胚数、胚胎评级。
- 冷冻/移植记录、内膜厚度和形态、黄体支持、移植胚胎数和质量。
- 妊娠结局、生化妊娠、临床妊娠、流产、异位妊娠。
- 实验室备注：精子处理、卵子质量、受精异常、胚胎发育阻滞。

## 输入完整性分级

### A 级：完整生育单元资料

可进行较完整的夫妻或生育单元层面推理。

### B 级：关键资料基本完整但有缺口

可提出主要假设，但必须列出缺口及其可能影响。

### C 级：单方资料

只能进行单方因素评估。不得诊断夫妻或生育单元层面的不明原因不孕，也不得完整归因。

### D 级：碎片化资料

只能做资料整理、风险提示和补充资料清单。

## 单方资料降级规则

若只有女方或卵子来源方资料，输出：

“当前仅基于卵子来源方/妊娠承载方资料进行评估；缺少精子来源方生殖史和精液分析，因此不能完成生育单元层面的不孕原因归因，也不能诊断不明原因不孕。”

若只有男方或精子来源方资料，输出：

“当前仅基于精子来源方资料进行评估；可以分析男方因素可能性，但不能单独判断夫妻整体生育预后或最佳 ART 路径，仍需结合卵子来源方年龄、卵巢储备、输卵管、宫腔和既往周期资料。”
