# 红旗症状与升级规则

## 总原则

出现红旗时，不再继续普通问诊流程。应先提醒患者尽快联系当地急救电话、急诊或线下医生。可以同时帮助整理“急诊就医摘要”。

不要说“请继续观察”来替代急救建议。

## 通用红旗

- 意识不清、昏迷、抽搐、严重嗜睡或突然行为异常；
- 呼吸困难、嘴唇发紫、血氧明显下降；
- 持续或严重胸痛、胸闷伴出汗/恶心/放射痛；
- 突发单侧肢体无力、口角歪斜、言语不清、视力突然改变；
- 大量出血、呕血、黑便、便血、咯血；
- 严重过敏：呼吸困难、喉头紧、面唇舌肿胀、全身风团伴头晕；
- 剧烈腹痛、腹膜刺激征、持续呕吐不能进水；
- 高热伴颈强直、皮疹、意识改变；
- 严重外伤、头部外伤后意识异常、脊柱损伤风险；
- 药物过量、中毒、误服危险物；
- 自伤、自杀或伤害他人风险。

## 妊娠及产后红旗

- 妊娠期阴道大量出血；
- 妊娠期剧烈腹痛或肩痛，尤其伴晕厥；
- 妊娠期严重头痛、视物模糊、上腹痛、明显水肿；
- 胎动明显减少；
- 产后大出血、发热、胸痛、呼吸困难、严重头痛或精神异常。

## 儿科红旗

- 小婴儿发热，尤其 3 月龄以下；
- 呼吸费力、呻吟、发绀；
- 反复抽搐、意识异常；
- 明显脱水：尿少、哭无泪、眼窝凹陷、精神差；
- 紫癜样皮疹、颈强直；
- 持续高热不退或精神状态明显差。

## 男科/泌尿红旗

- 急性睾丸疼痛或阴囊肿胀，需警惕睾丸扭转；
- 尿潴留伴明显疼痛；
- 血尿伴血块、发热寒战或腰痛；
- 会阴部剧痛伴发热或感染扩散表现。

## 输出要求

红旗场景下输出：

1. 明确说明存在需要线下紧急评估的风险；
2. 建议立即联系急救/急诊/线下医生；
3. 简短列出就医时需要告诉医生的关键信息；
4. 不输出具体诊断结论或居家治疗方案。
