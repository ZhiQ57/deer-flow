# 输出模板

## 模板一：继续问诊

```markdown
我先帮你把情况整理成病历。为了安全起见，我想先确认几个关键问题：

1. [问题一]
2. [问题二]
3. [问题三]

如果现在有 [红旗症状列表中的相关表现]，请优先就近急诊或拨打当地急救电话。
```

## 模板二：信息不足版病历

```markdown
# 预问诊病历草稿（信息不足版）

## 信息完整性
当前资料不足，以下内容仅根据患者已提供信息整理，不能作为诊断结论。

## 主诉
[患者主要不适 + 持续时间]

## 现病史
[按时间顺序整理]

## 已知伴随症状
[列出]

## 尚未确认的重要信息
- [缺失信息 1]
- [缺失信息 2]

## 红旗风险
[无已知红旗 / 存在红旗，建议急诊]

## 医生复核重点
- [重点 1]
- [重点 2]

## 患者可直接对医生说
“[一句话摘要]”
```

## 模板三：完整结构化病历

```markdown
# 结构化预问诊病历

## 1. 信息完整性
[完整/部分完整/明显不足；说明缺失项]

## 2. 患者基本信息
- 年龄：
- 性别或相关生理背景：
- 信息来源：

## 3. 主诉
[主要症状 + 持续时间]

## 4. 现病史
[起病、部位、性质、程度、变化、诱因缓解因素、已处理]

## 5. 伴随症状
[阳性症状]

## 6. 已询问并否认的关键症状
[只有明确问过且患者否认的内容]

## 7. 既往史
[慢病、既往诊断]

## 8. 手术/外伤/住院史
[如有]

## 9. 用药史
[药名、剂量、频率、近期变化]

## 10. 过敏史
[药物/食物/其他]

## 11. 家族史
[相关疾病]

## 12. 个人史/社会史
[吸烟、饮酒、职业暴露、旅行接触史等]

## 13. 特殊人群信息
[妊娠、哺乳、儿童、老人、免疫抑制等]

## 14. 客观资料
[生命体征、检查报告、家庭测量数据]

## 15. 红旗风险
[存在/未发现/未充分询问]

## 16. 初步分诊建议
[非诊断性建议，例如建议门诊、尽快线下评估、急诊]

## 17. 待补充信息
[列表]

## 18. 医生复核重点
[列表]

## 19. 患者就诊简短表述
“[适合患者复制给医生的一段话]”
```

## 模板四：红旗急诊摘要

```markdown
# 急诊就医摘要

## 为什么建议尽快就医
[红旗症状及风险说明，避免诊断化]

## 目前最关键情况
- 主诉：
- 起病时间：
- 严重程度：
- 伴随症状：
- 既往重要疾病：
- 正在用药/过敏：

## 到急诊需要主动说明
- [重点 1]
- [重点 2]

请尽快联系当地急救电话、急诊或线下医生。线上整理不能替代急诊评估。
```
