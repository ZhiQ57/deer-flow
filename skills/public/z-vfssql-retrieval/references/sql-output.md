# SQL 生成与结果交付

## 生成前确认

- **结构**：SELECT、过滤、时间、分组、排序和 JOIN 字段均已读取；桥接表也有结构依据。
- **值与口径**：使用已核验的原始值；时间范围、时区、状态过滤、金额口径和聚合粒度明确。未确认的简称或阈值不能写成确定条件。
- **关联**：两端字段、方向与基数有依据；一对多时必要的明细预聚合或去重经过推敲，不能用 DISTINCT 随意掩盖重复累计。
- **方言**：来自目标业务环境或实际 DDL；标识符、日期函数、除法和分页语法与之相符。索引 PostgreSQL 不代表业务目标也是 PostgreSQL。
- **参数**：单条只读查询，表名使用工具返回的公开名；用户值通过 `:name` 与 parameters 绑定，空值使用符合语义的 NULL 判断。

## 按用户目的交付

| 请求 | 交付 |
| --- | --- |
| 结构、字段或规则说明 | 已确认事实与公开来源路径；需要时附实际行号/读取范围 |
| SQL 草稿 | SQL、必要参数、指标/时间口径和依据，标注未执行 |
| 真实业务数据 | 成功执行后的结论、必要结果和采用的口径；按需附 SQL |
| 关键依据缺失 | 已确认部分、影响答案的缺口与具体澄清问题 |

解释采用的规则及来源即可，不机械输出固定模板或全部检索过程。用户要求的指标定义缺失时，先澄清该指标；只有用户需要替代指标时才提供另一套 SQL。

## 执行结果

`ok=true` 且 `executed=true` 后才报告执行成功。空 rows 表示本次条件没有返回记录；聚合得到 NULL 与数值零分别解释。disabled/rejected/timeout/error 不能当作零或空业务结果。

按 columns 与 rows 的位置解释值，保留类型标签中的精度、日期时区和单位。truncated=true 时注明本次结果不完整；需要总数或总额时让数据库做 COUNT/SUM/分组，不在截断明细上推算总体。row_count 仅为返回行数。

执行错误先核对公开结构、参数类型与方言；只有有新依据时才修正重试。超时收窄范围或查询量；相同失败不反复重试。执行不可用时交付已核验、明确未执行的草稿。
