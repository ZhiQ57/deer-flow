# 检索决策示例

以下为合成场景。路径、表字段、原始值和关系均需替换为当前索引已返回并核验的内容；示例路径不是默认挂载约定。

## 多表指标与简称

用户需要“柯尼打印机的销售额”。路径未知时查看默认目录，再分别搜索指标和实体，避免整句无命中掩盖局部线索。

```json
{
  "name": "vfs_tree_folder",
  "arguments": {}
}
```

```json
{
  "name": "vfs_grep_file",
  "arguments": {
    "paths": [
      "<已发现的业务目录>"
    ],
    "querys": [
      "销售额",
      "柯尼",
      "打印机"
    ],
    "top_k": 20
  }
}
```

读取实际命中的产品、订单和明细 desc.md。用字段注释、枚举或样本确认“柯尼”是否对应原始值“柯尼卡打印机”；若还命中扫描仪，进一步核对产品类型，不选第一个结果。

```json
{
  "name": "vfs_cat_read",
  "arguments": {
    "file_path": "<命中的desc.md路径>",
    "show_line": true
  }
}
```

检索并读取销售额定义和关联依据，核对取消状态、金额归属和明细基数。口径、实体、时间和字段齐全后生成参数化 SQL，按用户的数据请求执行；缺少销售额定义时先澄清，不擅自换成订单总额。

## 找文件与读取长文件

用户给出目录并要求定位结构文件时按名称查找，无需搜索整库正文：

```json
{
  "name": "vfs_find_file",
  "arguments": {
    "folder_path": "<用户提供的虚拟目录>",
    "type": "file",
    "patterns": [
      "desc.md",
      "ddl.sql"
    ],
    "exclude_dirs": [],
    "max_results": 30
  }
}
```

只有用户确实要找“最近更新的索引文件”时才增加 modified_within_days；查询“最近更新的订单”应核验业务时间字段并执行 SQL。

若 grep 命中第 142 行，而 cat 全文读取被截断，围绕该行读取原文：

```json
{
  "name": "vfs_sed",
  "arguments": {
    "file_path": "<命中的文件路径>",
    "operation": "print_range",
    "start_line": 132,
    "end_line": 152
  }
}
```

上下文仍不完整时按实际需要扩展相邻范围。单行持续超限时报告证据不完整，不重复整文件读取，也不通过替换预览改写原文后声称获得完整依据。

## 缺少指标口径或值映射

用户要求“优秀客户”，但结构只有客户信息，证据文件未给出优秀定义。返回已找到的客户表及缺口，询问按消费额、复购次数还是用户指定标准；不自行设置阈值或编造评分字段。

同样，完整 grep 无匹配且枚举/样本没有某个简称时，只能报告索引不足以确认其原始值，不能报告业务记录为零。用户补充明确口径后可继续本轮查询；只有要求保存或已授权学习时，才进入[知识提交](knowledge-learning.md)。
